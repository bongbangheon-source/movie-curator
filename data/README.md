# 실습용 가상 데이터

모든 작품, 가수, 소개는 실습을 위해 만든 가상 정보입니다. 실존 작품이나 인물과 일치하더라도 우연입니다.

- `movies.json`: 영화 30편. `id`, `title`, `genres`, `runtimeMinutes`, `moodTags`, `description`을 포함합니다.
- `music.json`: 음악 30곡. `id`, `title`, `artist`, `genres`, `moodTags`, `energyLevel`을 포함합니다.
- `id`는 두 파일 전체에서 고유한 문자열입니다.
- `genres`와 `moodTags`는 문자열 배열입니다. 공통 분위기 태그로 영화와 음악을 함께 분류할 수 있습니다.
- `runtimeMinutes`는 분 단위 정수입니다. 65~180분이며 90분 이하, 91~120분, 121분 이상이 각각 10편입니다.
- `energyLevel`은 1~5의 정수입니다. 1은 매우 차분함, 2는 차분함, 3은 보통, 4는 활기참, 5는 매우 활기참입니다. 각 수준에 6곡씩 있습니다.
- 영화와 음악은 각각 장르 10종을 3개씩 포함합니다. 같은 장르에서도 분위기와 상영시간 또는 에너지가 다릅니다.

현재 화면은 이 파일을 읽거나 검색하지 않습니다.
